🚀 Featured Projects
1. ClickMap USA — Interactive Elementor Map
A native Elementor widget that turns a U.S. map into an interactive, state-by-state experience. Every state is a real, focusable button: visitors can hover to reveal its name and click to open its assigned link. Each state can be styled independently through Elementor controls.

What makes it different:
- Inline SVG map — no iframe or external embed.
- Native Elementor controls for per-state links and styling.
- Keyboard-focusable state buttons for better accessibility.
- Scalable map that fits responsive layouts and inherits site typography.
WordPress Elementor PHP JavaScript SVG Accessibility
2. Custom Minimalist Mailer (CMM4)
A modular WordPress form and email plugin built around practical submission management. It includes submission logging, secure file handling, CSV export, and an optional job-application synchronization add-on for Google Sheets and Google Drive.

WordPress PHP JavaScript Google Sheets API Google Drive API
3. Advanced Kinetic Slider
A custom Elementor slider widget focused on expressive motion and flexible content presentation. It supports image and video backgrounds, transition effects, keyboard navigation, ARIA support, and reduced-motion handling.

WordPress Elementor PHP JavaScript CSS Accessibility
4. NinaVoiceBot — Telegram Voice Assistant
A self-hosted Telegram assistant that accepts text and voice messages, processes speech locally, maintains conversational context, and generates replies using a locally hosted language model. The workflow connects n8n, PostgreSQL, Whisper.cpp, and Ollama, with optional text-to-speech output.

n8n Telegram Bot API PostgreSQL Whisper.cpp Ollama Python FFmpeg
